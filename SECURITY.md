# Security Policy

## Reporting a vulnerability

Please report security issues privately through GitHub: open the
[Security tab](https://github.com/nmorton13/hodljuice-cli/security) of this
repository and choose **Report a vulnerability**. Please don't open a public
issue for anything security-related.

Include what you found, how to reproduce it, and which version of `hj` or the
Claude Code plugin you were using. You should hear back within a week.

## Scope

- The `hj` CLI (`src/hodljuice_cli`) and its Homebrew formula
- The HodlJuice Claude Code plugin (`claude-mod`), including its hooks and
  commands
- The hosted MCP server at `https://hodljuice.app/mcp`, as configured by the
  plugin

## Supported versions

Only the latest release receives fixes.
